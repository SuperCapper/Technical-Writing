# 18. Presentations

Skill ID: `style-support.presentations`

Structures a technical presentation into title, overview, discussion, and summary slides, matched to the speaking situation (impromptu, extemporaneous, manuscript) and purpose (informative, demonstrative, persuasive, or a technical update combining purposes), while controlling slide complexity and special effects.

Source: *Technical Writing for Engineers and Scientists (ISE)*, Chapter 18 -- Presentations.

## Checklist

- [ ] Do I understand who my audience is, and the occasion and purpose of this presentation?
- [ ] Do I know the physical context in which I will present?
- [ ] Am I presenting substantive, relevant information, organized effectively for this audience?
- [ ] Have I included a title slide, an overview slide, and a discussion slide for each overview topic?
- [ ] Have I included a summary slide, and reflections/contact slides only if necessary?
- [ ] Are all slides readable when projected, using a consistent, uncluttered design scheme?
- [ ] Have I avoided unnecessary complexity and special effects, and evaluated the room/equipment beforehand?
