# 9. Progress Reports

Skill ID: `genres.progress-report`

Drafts or reviews a progress report against an already-accepted proposal, following Outline 9.1: reference the originating proposal, restate the problem and proposed solution, report tasks completed and remaining, and close with an appraisal and forecast.

Source: *Technical Writing for Engineers and Scientists (ISE)*, Chapter 9 -- Progress Reports.

## Checklist

- [ ] Do I understand what the audience for this report wants and requires?
- [ ] Have I specified the purpose, background, and scope of this report?
- [ ] Have I referenced the accepted proposal by name, number, and/or date?
- [ ] Have I reviewed the problem and proposed solution from that proposal?
- [ ] Have I specified the tasks included in this report and reported completed vs. remaining tasks accurately?
- [ ] Have I provided an honest appraisal and forecast in the conclusion?
- [ ] Have I formatted the report to match audience expectations and make it easy to skim?

## Usage
