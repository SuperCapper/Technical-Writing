# 5. Description of a Mechanism

Skill ID: `elements.mechanism-description`

Drafts or reviews a description of a mechanism following Outline 5.1: an introduction that defines the mechanism and its overall function, a part-by-part body where each part is named, defined, and its function explained, and a conclusion that ties the parts back into how the whole mechanism works.

Source: *Technical Writing for Engineers and Scientists (ISE)*, Chapter 5 -- Description of a Mechanism.

## Checklist

- [ ] Have I defined the mechanism and stated its overall function or purpose?
- [ ] Have I listed the mechanism's major parts, in the order I discuss them?
- [ ] Have I defined each part and described its individual function?
- [ ] Have I described how each part relates to the parts adjoining it?
- [ ] Have I concluded by explaining how the parts interrelate to produce the whole mechanism's function?
- [ ] Do all visuals relate directly to the text, carry a sequence number, and get referenced before they appear?
